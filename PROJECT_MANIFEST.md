# Project Manifest

This repository contains privacy-safe derived analysis tables, data-quality reports, dashboard validation notes, and reference assets for the Gift Commerce Intelligence portfolio project.

The original customer source CSV and Excel workbooks have been removed from the current public branch because the source material included direct identifiers such as names, phone numbers, emails, and addresses. The main workbook is not included in this public copy pending a full privacy review.

The `reports/data_profile.csv` file records column-level checks for source and derived tables. The `reports/workbook_profile.csv` file records the structure of the original workbook, and `reports/dashboard_validation.csv` records the earlier dashboard headline checks. These reports are historical artifacts and do not mean the current public copy can independently reproduce the workbook.

**Privacy remediation is incomplete until the repository is made private and its Git history is reviewed/cleaned.** Do not re-add original customer-level files or workbooks until all sheets, hidden data, pivot caches, and exported assets have been checked for personal information.
