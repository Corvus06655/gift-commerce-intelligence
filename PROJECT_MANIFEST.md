# Project Manifest

This project was assembled from the supplied `orders_fixed.csv`, `customers.csv`, `products.csv`, `Book2.xlsx`, and dashboard PDF. The repository intentionally includes only non-sensitive analysis inputs and privacy-reduced outputs. Direct customer contact numbers, emails, and addresses are excluded.

The `reports/data_profile.csv` file contains column-level checks for the three source CSV tables and every derived analysis table. The `reports/workbook_profile.csv` file records the structure of every workbook sheet. The dashboard headline checks are in `reports/dashboard_validation.csv`.
